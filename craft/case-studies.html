Case Studies

How award-level sites were actually built - the decisions, the math, and the lessons, each linked to its write-up.

Award-site case studies

Study the method; never copy assets or code.

Igloo Inc (Site of the Year 2024; abeto with Bureaux) awwwards.com/igloo-inc-case-study.html

  • Only three sections, so the whole job was making the scroll engaging with interactive moments (a small page can still be great: depth over page count).
  • Process: moodboards from the client -> grey mockups and sketches mapping user journey, key interactions and navigation -> simple "previs" animations (untextured renders) for hard-to-mock sections -> build code and 3D together in the browser with live-tweaking tools.
  • Measure performance during development, tune for low-end devices.
  • Tone check: opening on an outdoor scene felt off-brand for a future-forward company, so a real-time in-engine intro animation was added (small file size, consistent style, easy edits).
  • Variation: one ice block per project because identical blocks looked samey when scrolling; a procedural crystal-growth algorithm made many unique ones (choose procedural only when time saved exceeds setup).
  • Footer: interactive particles forming shapes from compressed volume data (custom exporter smaller than a typical image).
  • One consistent look device: chromatic aberration + displacement + frost for scene transitions.

Lando Norris (Site of the Year 2025; OFF+BRAND, WebGL by Adrian Gubrica) Codrops

tympanus.net/codrops/2025/12/05/from-illusions-to-optimization-the-creative-webgl-worlds-of-adrian-gubrica/ - Hardest part was optimisation: many iterations per 3D element; layers and render targets for masking the helmet hero (several variants). - Syncing each WebGL scene with its DOM element on mobile with several scenes rendering at once; prioritise to minimise delay. - Fake expensive material properties: replaced a 3D glass layer with a fract function + noise + a reflection texture; same look, more layout control, big performance saving. - Uses ogl.js (smaller bundle than three.js, good with render targets) on commercial projects; Blender + Photoshop for assets; gltf-transform CLI for precise GLB optimisation. - Another write-up claims the site is vanilla JS without a framework (LinkedIn post, unverified) and a 19 kB library recreating the hero effect exists (dev.to/idlecyrex, unverified, check licence before using). Lesson: fake it with textures and math, ship small bundles, compress GLB, test mobile early.

Messenger (Site of the Year 2025; abeto) awwwards.com/messenger.html

  • Started from a feeling (calm but slightly weird) and real references (videos of mid-sized Asian cities, research trips). Art direction from lived references, not from other websites.
  • Technical constraint turned into style: a tiny spherical world (dynamic camera, upright text/trees, central gravity); modelled as an "unwrapped cube" because it maps to a sphere with minimal distortion, after procedural deformation proved too slow. Lesson: pick a concept strong enough to dictate structure; derive visuals from real-world reference.

Cross-cutting patterns

  1. Concept-first, then journey, then effects. 2. Few sections, deep interactions. 3. A consistent signature effect. 4. Performance is part of design (budget, compress, fake expensive things). 5. Prototype in the browser. 6. Variation per item to avoid sameness.

Lusion (studio site, Awwwards Site of the Month May 2019; later v3 was SOTY 2023) - note: this is the 2019 v1 case study, not v3

  • Designers and developers worked together so every visual used custom assets, instead of the usual creative -> design -> dev handoff.
  • "You don't need to do everything real-time": bake. Cloth sim pre-computed in Houdini into an ArrayBuffer and blended on user input; character cloth stored as position/normal PNG textures (11 keyframes for 66 frames, 16-bit ints with a divider, ~983KB desktop / 246KB mobile); 3D model lighting pre-rendered into images plus matcaps; an offline-rendered video synced to the real-time scene via a binary frame counter read back with readPixels.
  • Stack: three.js, tweenlite, webpack, node static-site generator, purely static hosting.
  • They chose a playful, technical design over trendy minimalism to leave room for technical showing-off (match design to what the site must prove). Lesson: bake heavy effects into compact assets, keep the site static, tailor assets to the effect. Not yet read: Lusion v3 and Noomo and Mana case studies (search: awwwards.com/sites/lusion-v3, awwwards.com/sites/mana-yerba-mate). Mana Yerba Mate (SOTD, Louis Paquet): Awwwards page lists only highlights ("3D scrolling animation" element, 8.03/10); no making-of text found. Not used.

Noomo Labs (Awwwards making-of, Jul 10 2024) (source)

  • One hero object: a glass-encased 3D jellyfish; the sphere shatters (Cannon.js physics) and the shards persist across pages, different each load. Glass done as two meshes (texture + modified glass material).
  • Stack stated: Three.js + GSAP (no react-three-fiber, for flexibility), Blender for baked non-interactive animation, Nuxt as framework. All 3D in one scene; camera moves hand-animated.
  • Performance choices stated: no post-processing on main page; three glass types, the invisible ones disabled; simplified geometry; on mobile lower glass quality and fewer physics simulations.
  • Engagement claim (theirs, unverified): a user colour/texture customiser raised average visit to almost two minutes.
  • Sound: subtle effects plus calm background music, not overwhelming.

Awwwards breakdowns: Igloo, Messenger, Gubrica

Igloo Inc (abeto × Bureaux, Awwwards SOTY 2024)

  • Process: grey mockups to map journey → "previs" untextured animations for sections static mocks can't communicate → code + 3D art simultaneously IN the browser with custom real-time shader/texture/model tools; continuous perf measurement for low-end devices.
  • Scene transitions = chromatic aberration + tech displacement + frost; the aberration was DISCOVERED in-build during experimentation, then adopted across materials — house pattern: let the build propose the aesthetic.
  • Ice blocks: each project = an object in procedurally "grown" ice (custom algorithm mimics crystal growth in a container) — picked over hand-modeling for future scalability, with the caveat they logged: "procedural approaches need to be chosen carefully, setup can take significant time."
  • Particles: VDB volume → custom exporter → compressed browser format smaller than a typical website image; particles colour by speed, glow on shape-shift; Bureaux supplied music/SFX matched to movement.
  • UI in WebGL for two effects: glitch (cheap shader vs expensive CSS clip/mask) and text scramble (SDF texture offset vs style-recalc churn). Stack: Three.js, three-mesh-bvh, Svelte, GSAP, Vite; Houdini + Blender; custom geometry exporters + background shader compilation for load time.

Messenger (abeto, Awwwards SOTY 2025)

  • Tone target: "calm but a little bit weird" (mid-size Asian city vibe); 15-min free multiplayer game as R&D vehicle.
  • Tiny-planet world: "unwrapped cube" modeling beat procedural deformation — cube→sphere with minimal distortion and far faster iteration.
  • Look: hand-drawn imperfection via a custom outline system (per-pixel control of thickness/colour/transparency); whole-game mood swaps via a 16x16 colour-atlas texture; blob-forests auto-swapped for stylised shader foliage; wet-clothes colour change that dries off.
  • Perf: custom LOD preserving silhouettes (minimises popping); WebAssembly-generated glyphs rendered by GPU instead of MSDF for sharp type at angles; iOS Safari memory discipline — track every asset, free the moment unused, custom split/compress tools.
  • UX/accessibility: one finger on mobile, mouse-only on desktop, smart auto-follow camera; success test = non-gamer relatives play with zero instruction. Multiplayer: 10-player room cap to protect calm; 3D emoji instead of text chat (no moderation, universal). Players self-organised as guides because the game doesn't hand-hold.
  • STORY WRITTEN LAST: simplest premise (delivering messages, no chosen-one stakes) won after sci-fi/crime plots didn't click — the lack of pressure IS the design. Stack: Three.js, three-mesh-bvh, vanilla JS, C++; Houdini, Blender, Figma, Photoshop.

Adrián Gubrica (OFF+BRAND) — Codrops spotlight

  • Lando Norris (SOTY 2025): helmet hero has 4 versions + easter egg (layered render targets for masking); 24 track visualisations with 490 points each; WebGL↔DOM sync on mobile solved by prioritising the render loop (credit Federico Valla).
  • Webflow 2026 report: couldn't match C4D raytraced glass — FAKED it: fract + noise replaced the glass layer, custom texture simulated reflections/shadows, textured planes replaced DoF background. Rule: fake material properties with math + textures when raytraced fidelity is unreachable; got layout control AND performance.
  • Toolbox shift: ogl.js over Three.js on commercial work (smaller bundles, multi-render-target performance) + gltf-transform CLI for precise GLB optimisation.
  • Philosophy: keep the designer mindset, don't become "the grumpy dev"; cross-train in VFX (attention-directing, believable illusions) and animation (elemental principles); understand tools deeply to stay in control (Hawking quote).

three.js discourse Igloo thread: low yield — community praise only, no technical content; noted that particles drew Lusion comparisons.

Lando Norris hero reverse-engineered + Messenger counterpoint

The Lando hero effect is a FLUID SOLVER, not a brush mask

  • Alexandru Pavelescu tried to copy the landonorris.com hero (drag across the face, helmet tears open with a wet ragged edge, heals back) as a brush-trail mask and failed on two behaviours: the reveal keeps spreading ~1s after the pointer stops, and it has HOLES — islands of original image inside uncovered area. He read OFF+BRAND's public CDN shader: the cut thresholds the VELOCITY FIELD of a fluid solver. Momentum explains the outliving wave; vortex cores have no velocity at centre, which explains the holes. Method note: reading the shipping shader on a public CDN is a legit reverse-engineering route.
  • His MIT reproduction revealed (github.com/idleCyrex/revealed, 19.2 kB gz, zero deps, WebGL1, no float textures): RGBA8 mask, red channel = reveal, velocity in the two spare channels — the fluid character without shipping a solver. One heal-rate number drives modes: persist (0), spotlight (infinity), trail (between), plus scroll-driven progress. Fails safe: the front plate is a real DOM img, so no-WebGL/reduced-motion/lost-context all degrade to the plain image.

OFF+BRAND Lando case study

  • Thin on tech (marketing copy), one structural fact: the SOTY 2025 site is built on WEBFLOW + custom WebGL/3D/Rive layers — award-grade WebGL does not require a fully custom stack. Design system "balances McLaren racing heritage with Lando's playful energy" (bold type, vibrant accents, cinematic scroll). Awards: Awwwards SOTY + SOTM + SOTD, FWA, CSSDA.

Messenger counterpoint — CommArts interview with Vicente Lucendo (abeto)

  • Note: team was TWO people; almost everything custom (shaders, controls, camera, networking, backend) on three.js; the small-planet layout existed to kill invisible walls (walk straight, circle the world); outlines + colour committed early for the "indie touch". REGRET: "we'd probably think about the story first instead of leaving it for the end" — so "story written LAST" is what happened, NOT their recommended process. Logged as a nuance, not a rule. 10-player cap came from testing (more broke the calm); hundreds still online months later.

Tekprivacy rebrand - Another Collective

Source: https://www.anothercollective.pt/projects/tekprivacy (Behance gallery behance.net/gallery/242173443/Tekprivacy blocks fetchers) - Data-protection rebrand built on one metaphor: focus and blur - information that exists but is deliberately kept out of reach. Backgrounds, gradients, imagery and digital applications all play with layers of visibility and distortion (reveal/conceal/direct attention). - Custom logotype + symbol drawn from a squared grid, from structured digital systems. Goal: technological without predictable tech codes; restrained but distinctive; keeps trust/authority. - Lesson: a single strong conceptual metaphor applied across every surface beats a bag of tech tropes. For security/privacy products, blur/focus is an ownable mechanic that doubles as UI behaviour (scan = focus).

Codrops case studies: Heron + Chasing the Moment

Sources: tympanus.net/codrops/2026/10/12/heron-ai/, tympanus.net/codrops/2026/10/12/chasing-the-moment/. - HERON by Bearplus (AI agent for architects): DESIGNING AI WITHOUT THE "AI" LOOK. Midway, the team stripped the word "AI" from the brief: "if you stripped the word AI out entirely, what would a tool that helps architects catch and fix problems actually look like?" Answer: the visual language the audience already trusts - floor plans, dimension lines, redline markup, Revit-style information layout. Base stays calm (off-white, near-black, drawing grid); the AI only shows itself when the system notices or acts. RED AS SEMANTIC, NOT DECORATION: in drawing/inspection workflows red means attention needed, so red appears almost exclusively on violations/alerts - "the less color noise there is, the more weight a warning carries." Homepage rebuilt around the product's real workflow (Observe -> Advise -> Act -> Learn) as the scroll's narrative spine instead of a feature list. Grid follows a DRAWING SHEET not a landing page: metadata/labels run to viewport edges like a drawing mid-annotation; one focal point per section to avoid text-left/image-right rut. First direction (architectural editorial/brutalist) was beautiful but wrong: "it made Heron look like a studio or a publication, not software doing something." Craft-standards note: "The client liked it. We didn't. So we held off on sign-off." Hero interaction: drag across an ordinary drawing to reveal buried violations - pointer-to-reveal mapping near 1:1 because "too much easing and it feels like an effect; direct enough and it feels like a tool." Plain DOM + coordinate math over WebGL when the visual language is 2D (and object-fit letterboxing means you must measure the image as displayed and remap markers). - CHASING THE MOMENT by Canberk Polat (a WEBFILM - short film in the browser, Three.js+GLSL): the tech stack as film production - "Three.js and GLSL became its set, its camera and its lights." Five scenes as a faceless runner's arc (endless run, time pressure, crowd surveillance, lost floating, unreachable diamond) - the faceless protagonist "could be anyone building something." Film ends, then the webfilm "turns into an invitation." LOADER AS TICKET: real Blender geometry (10.6k tris, 296 KB) with runtime Canvas 2D print - the ticket's date/time come from the VISITOR'S OWN CLOCK, "so the ticket belongs to the moment you watched the film." Craft detail: it's the only model NOT Draco-compressed because Draco rounds numbers and the print must sit at exactly u=0.76 (the tear seam). glTF UV gotcha: flipY=false or the print renders upside down. Paper curl via fold-line cylinder math (paper doesn't stretch: flat distance becomes arc length, angle = d/r). All SFX except music synthesized in-browser (Web Audio API); Chopin Prelude Op.28 No.4 as score; film half runs its own virtual scroll, GSAP+Lenis only on the invitation half.

Codrops case studies: Goodgrowth + Sixty Frames

Sources: tympanus.net/codrops/2026/08/27/goodgrowth-boot-sequences-spinning-discs-and-the-art-of-the-portfolio/, tympanus.net/codrops/2026/08/22/sixty-frames-for-the-record-a-three-js-game-seven-fly-throughs-and-a-wall-of-crts/. - GOODGROWTH by Matt Stone (console-boot-nostalgia portfolio, vanilla JS+Three+GSAP+Lenis): late-90s PlayStation/Dreamcast startup screens as the feeling - "powering on a console and revealing the experience." "Insert Disc" screen doubles as the audio opt-in gate (sound designed in from preload, not an afterthought; load numbers swap O's for 0's in the logo). A SPIRAL IS NOT A PATH: "it's just angle increasing while radius decreases" - each thumbnail stores angle+radius separately, a ticker converts to x/y per frame, and the gather tweens orbit angle up while collapsing radii; a 0.09 stagger gives the tail ("trailing thumbnails are still orbiting while the leaders have vanished"). GLOBE: orthographic projection is a STRUCTURAL look decision (perspective bulges meridians near the poles; ortho keeps the nested-ellipse reference exact); project band = single texture atlas with a LATITUDE SHIFT not a rotation so it hugs the sphere. Invisible-craft detail: meridian counter-rotation ratio snapped from 0.6 to 0.571 so one detent step = exactly one meridian step - "every rest pose reproduces the reference layout." Mobile swipe fix: commit exactly one step from where the gesture STARTED, not from the half-rotated current value (a light swipe previously did nothing). Built with Claude Code in the workflow to reach past his HTML/CSS/JS base. - SIXTY FRAMES by Filip Zrnzevic (Three.js lab around his own music: FRONTIER game + 7 LXSTNGHT fly-throughs + CRT wall): the constraint is the method - "a demo can be a tech showcase; a release has to hold a mood for three and a half minutes at 60 fps on whatever machine the listener owns." PERFORMANCE RECEIPTS (measured, stealable): (1) BUDGET PIXELS NOT DPR - dpr=2 on a big window is a 9.7MP buffer; cap an absolute pixel budget (5.2MP, LOW/HIGH tiers) and derive DPR from it. (2) NEVER mix-blend-mode OVER A WEBGL CANVAS - a fullscreen DOM veil cost 30-45ms/frame in Skia's slow compositing path, invisible to in-page profilers; re-grade as a fused composer effect in ~15 lines of GLSL. "If you're grading a canvas, grade it in the canvas." (3) LIGHTS TOGGLE INTENSITY, NEVER VISIBILITY - Three.js bakes light count into every lit material's program cache key, so toggling visible recompiled ~20 programs mid-fight (dead stops "always during an explosion"); intensity 0 keeps the slot (programs 140->98, mid-fight compiles -> 0). (4) MERGE THEN RE-SEGMENT: 1,421 draw calls -> 25 by baking matrixWorld + grouping by material, but one 30m mesh defeats frustum culling (it submits what's BEHIND you too) - re-merge per material per 3m z-segment (-21-37% submitted tris). (5) Bake per-object identity (bbox center + hash) into vertex attributes BEFORE merging so merged geometry can still animate per-panel. SHADER GROUND: after four rejected floor textures, one analytic hex-lattice ShaderMaterial with fwidth AA - "no texture, no mip chain, crisp at every distance"; but a custom ShaderMaterial is invisible to scene lights unless you include Three's shadowmap chunks ("the searchlight swept that board for a week and lit nothing until it became a uniform"). MENUS AS THINGS IN THE LANE: upgrade choices are hex gates you fly through (RingGeometry(r, r+0.34, 6) is a hex ring) - no modal, no pause, "the choice costs something." Audio hierarchy: "the soundtrack is the product, the SFX are punctuation" - one global ducking bus under the music. Series architecture: runtime dispatches on MATERIAL NAME (HullMetal -> triplanar + batching; Reactor* -> hidden light locator) so you can swap the GLB and keep the engine.

Codrops case studies: Yichen Xie + ULTRAGRID

Sources: tympanus.net/codrops/2026/10/06/yichen-xie-portfolio/, tympanus.net/codrops/2026/09/30/ultragrid-portfolio/. - YICHEN XIE (infinite bubble canvas portfolio, plain JS + WebGL2): PLAY AS THE OPENING - "the first few seconds should feel like an invitation to play": draw a bubble, watch it settle, pop one. Metaball outlines via SDF blending (soft joins where circles meet) but THIN RINGS with open interiors - keeps the image light while intersections get rich. Composition doctrine: each bubble has a FIXED anchor + small drift (4-8 CSS px per axis, 20-32s cycles, different phases so "you notice the spaces changing before you notice repeated motion"; mobile 60% amplitude). The drawing tool came first (Liquid, infinite canvas playground shared on X) - "drawing became a way of finding the composition"; the homepage then chooses from 3 saved compositions visitors can modify. Feedback after sharing added bursting. Practical role: bubbles give visitors something to do while project media loads, and "keeping the effect light was part of the design from the start" (it shares resources with the page). Engineering: ONE fullscreen triangle (vertices from gl_VertexID, gl.drawArrays(TRIANGLES, 0, 3) - no mesh to rebuild), fragment shader evaluates all outlines, up to 32 shapes as vec4 uniforms, burst particles on a SEPARATE transparent Canvas 2D layer, biography/nav/projects stay ordinary HTML. Coordinate gotcha: pointer CSS-px top-left vs fragment drawing-buffer bottom-left - divide by scale, flip Y, subtract half canvas. - ULTRAGRID by Thibaut Oung (3D isometric desk as navigation, Blender->Spline->Webflow): A DESK THAT SPEAKS BEFORE I DO. Origin: a prospect's rejection - "Make your website more about you as a person so it's easy to get to know the person that we're dealing with." "Step one wasn't a 3D tool at all. It was information architecture, disguised as furniture" - each desk object maps to a page (computer->work, photo frame->about). THE SITEMAP CAME BEFORE BLENDER. Asset coherence: low-poly Sketchfab bases, then REBUILD every material so the desk "reads as one coherent object, not a pile of things that happened to share a room" (wood: HSV warm + Brightness/Contrast + Invert->Bump grain before Principled BSDF; hygge warmth as the lighting intent against cold Copenhagen). Spline over Three.js for a visual-first designer. Optimization saga (the honest numbers): apply modifiers, curves->mesh, flatten armatures AT EXPORT, WebP textures via Squoosh (2048 large/1024-512 small), Decimate - still lands at 1.84MB, Loading Score 79/100, 277 objects (172 clones), 70k polys, 40 imported materials vs 10 native: "every one of those imported materials is a small tax on load time." CODE EMBED over Webflow's native Spline element or iframe: only the embed lets you (1) defer scene load until your own loader finishes and (2) toggle scene state (IconVis variable) from clicks in the regular DOM outside the canvas. Mentor lesson: ask someone who has done the Blender->Spline handoff what is realistic.

Codrops case studies: bleibtgleich'26 + Kononenko

Sources: tympanus.net/codrops/2026/09/23/bleibtgleich26-a-180-turn-from-brutalism-to-minimalism/, tympanus.net/codrops/2026/09/18/kononenko-architectural-bureau/. - BLEIBTGLEICH'26 by Maksym Ponomarenko (yearly portfolio rebuild, Webflow+GSAP+Three+Barba, fully vibecoded with Claude): the tagline means "stays the same" - the irony is the point; he rebuilds every year, this time a 180 from loud brutalism to "quiet calm minimalism... the site waits until you look closer." GOOEY TEXT REVEAL (no WebGL): SplitText cuts lines, each line gets an SVG filter - feGaussianBlur stdDeviation 30 + feColorMatrix alpha20-8 threshold, so "letters stick together into blobs as they blur instead of turning into fog"; animate ONLY stdDeviation 50->0 (reveal) and reverse (hide), opacity never touched. Known limit: per-line filters don't merge across lines - a single shared parent filter is the open problem for morphing text. CSS-ONLY IMAGE REVEAL (WebGL look, no WebGL): two clip-paths (container + inner img, userSpaceOnUse = pixels), a 12-point wave line with RANDOM vertical offsets per image ("no identical waves on the page"), baseY sweeps top->bottom while sin(progressPI) envelopes the amplitude (flat at start, full wave mid-reveal, flat at end), cubic beziers with midpoint control points, GSAP tweens a plain object and onUpdate rewrites the path d. Honest reuse: Lunardi's Infinite Canvas on the Experiments page + OSMO Barba transitions - credit named inline. - KONONENKO ARCHITECTURAL BUREAU by Artem Shcherban + Reksa Andhika (8-month identity->site collaboration, Nuxt 4 + vanilla SCSS + Prismic slices + Cloudflare Pages): CHOICE AS THE INTERFACE CONCEPT - "architecture rarely arrives at a final form immediately; architects compare possibilities" - so the projects page offers THREE WAYS TO EXPLORE: Grid (subtle parallax, projects introduced progressively, never a dense wall), List ("intentionally much simpler. Not every interaction needs to become an experiment" - the expressive parts only work balanced by quiet ones), and ACTIVE GALLERY (infinite scattered composition; hovering one project highlights every image of it - "scattered fragments become one body of work... from apparent chaos to structure"). Active-project hover reduces the others "almost to architectural outlines" - borrowing drawing language WITHOUT using drawings as decoration. Process: design and development shaped together from the start ("simple sketches became interface ideas; interface ideas became interactions; interactions pushed the design in new directions") with complete directness ("if something did not work, we said it"). Engineering: DOM stays source of truth - HTML laid out invisibly, rects measured, WebGL planes follow (enables morphing between grid/list/gallery and fullscreen-from-anywhere); sketch-reveal shader turns luminance into ink thresholded against scroll progress + noise ("the drawing appears unevenly, like it is being drawn"); WebGL loop runs on the GSAP TICKER (tweens, scroll and render share one clock). THE HARD CRAFT IS INTERRUPTIBILITY: "every layout morph, transition and drag had to be spammable: switch modes mid-morph, scroll during a transition, open fullscreen while the slider is still settling" - hand the document back at the very start of an exit, keep the morph running on its own clock. "It is invisible work, but it is worth the result."

Codrops case studies: House of Yellow + Depth

Sources: tympanus.net/codrops/2026/09/16/house-of-yellow/, tympanus.net/codrops/2026/09/13/building-depth-designing-and-developing-a-3d-renderer-inside-figma/. - HOUSE OF YELLOW (Ronald de Groot identity + Mees Verberne dev, content agency Eindhoven): MOTION AS IDENTITY, NOT DECORATION - identity designed "not only as static brand assets but with their digital potential in mind"; the site is the first living application, branding integrated into the interface rather than applied after. "We wanted motion to become part of the identity rather than something added on top of it" - one continuous system of movement instead of individually designed animations. PACE MIRRORS THE WORK: "fast when it needs to be fast, restrained when it needs to be restrained." Play button = FOUR INDEPENDENT MARQUEES circling the frame ("it feels like a button, but it also feels like an object"); logo animated over video, memorable but quick enough not to block. Made-by-Yellow archive: GRID FOR DISCOVERY vs LIST FOR INFORMATION (category, client, views, delivery time) - "two views deliberately feel like different ways of looking at the same collection" (cf. Kononenko's three modes). Custom players around Vimeo-served files (own the play states, overlays, loading). MorphSVG shape transforms TIED TO CONTENT: "the animation needed to help create the image that the text was describing", not a collection of impressive effects existing independently. Scroll predictability: "the motion follows the visitor rather than fighting them." - DEPTH by Aleksei Kipin (3D renderer Figma plugin, depth.fyi): built for the gap between design and the visualization team - "I didn't need final materials or production lighting. I needed enough form and light to judge whether the image worked on the page." Narrow MVP first (load model, move camera, change light, return image) watching how much 3D control fits inside a plugin window "without making the tool feel unfamiliar to someone who spends most of the day in Figma." Engineering notes: reduce rendering DURING camera movement, restore full quality for the placed image; 2x export doubles PNG pixels at the same canvas size; transparent materials need the scene background in export for convincing refraction. THE SITE TEACHES THE PRODUCT BY FOLLOWING THE ORDER A RENDER TAKES SHAPE: bare Form -> Material -> Environment -> Render catalogue, "introduces information one layer at a time" while the SAME object stays visible so each decision's effect is readable. HERO HYBRID (the stealable move): fully live 3D "looked like an interactive 3D experiment rather than the image I had in mind" - so two generated frames + a 360-degree interpolation became a 240-frame image sequence scrubbed by horizontal mouse position, with real-time 3D layers AROUND it; poster frame first, separate landscape/portrait media, heavy parts load later. Material transitions: the CONTROL responds immediately, the surface takes ~2s to sweep across the object (blend inside one opaque material so edges stay stable), and mid-sweep reversal works from the current position (cf. Kononenko interruptibility). Environment chapter: INVISIBLE HDRI supplies light/reflections while the VISIBLE mountain is a sparse point field sampled from real terrain - photographic reflections without a photographic backdrop crowding the black space.

Codrops case studies: Yestalgia + Still

Sources: tympanus.net/codrops/2026/09/12/yestalgia-bringing-decathlons-90s-spirit-to-life-through-a-playful-digital-experience/, tympanus.net/codrops/2026/09/09/still-from-akira-to-ink-wash-building-a-generative-garden-in-webgpu/. - YESTALGIA by Quentin Hocde + Jonathan Da Costa (Decathlon 90s capsule, WordPress custom theme in 7 languages): product-first editorial + pure-graphic INTERLUDES ("typography, shapes and movement take over... shifting the rhythm" between product moments). WALKMAN NAV: menu = cassette deck, each tape a destination; the physical snap came from a dev/motion-designer loop - dev built the working base, motion designer "pushed the easings, delays and durations much further", dev ported the settings back into code. The close-bounce (two very short tweens) is "like the click of a cassette seating in the slot." FAKE-3D EXTRUDED HEADLINES with zero 3D: each character doubled, the duplicate rides slightly behind; a stagger walks the reveal across the line and the DELAY between letter and duplicate creates the depth; fade-in runs much faster than the translate. Mobile splits by words for performance. REDUCED MOTION DONE RIGHT: every duration/stagger/delay drops to zero so the headline still assembles instantly, and Rive loops scrub to their LAST FRAME - "the composition still reads exactly as designed, it just doesn't move." Rive loops gated by IntersectionObserver (never burn GPU on motion nobody sees). THE INVISIBLE CONSTRAINT: "a heavily art-directed site still has to be genuinely easy to update" - every section is a Blockstudio block (JSON schema + twig template) so the client reorders/recomposes without code and without breaking the art direction. piecesjs web components lazy-import their own JS/CSS; scroll wired via data-attributes behind one Scroll Piece (Lenis + ScrollTrigger centralized). - STILL by Ming Jyun Hung: from Akira + Japanese folding screens he extracts a SHARED VISUAL LOGIC: "flat areas of color, clear edges, deliberate composition, woven surfaces, irregular marks that create atmosphere through shape, surface, and spacing rather than realism." WOODBLOCK TOON SHADING: quantize N*L into only TWO bands (one shadow, one lit - "more steps stop reading like print"), bands are tints on the base color, and add world-space noise to the threshold to break edges that look too clean. Outlines per-asset: inverted hull on the character, but mask-based rim on VAT-instanced petals (an extra mesh per petal would be expensive AND trace the wrong silhouette; "one texture handles both shape and edge"). INK-WASH GROUND SHADOW (from the Akira poster where the shadow is "soft at the edge, uneven inside, loosely following the silhouette, like paint thinned on paper"): invert the shadow map, smoothstep it into a broad wash, one noise field loosens edge AND mottles fill together; the darker contour sits just OUTSIDE the wash instead of tracing the silhouette; fwidth keeps line width steady in screen space; combine with max so overlapping masks never stack too dark. Second shadow map restricted to the flower layer so flowers shade the character but not themselves (a zero-intensity light still writes depth). SILK WEAVE OVER THE WHOLE FRAME (from Hōitsu/Kenzan hollyhock screens: "the grid and stains belong to the ground of the painting rather than to one object"): screen-space warp/weft threads with a jittered grid so it doesn't look machine-made, slow noise stains, multiplied over the scene color so the texture darkens the frame as a whole. PETAL SHEDDING (idea from teamLab's Flowers and People: "a flower reaches its fullest point just before it falls"): baked VAT bloom animation + a procedural pass on top - petal id and pivot packed into vertex color, hash-staggered timing, easing drives lift and outward fan. "Combining baked VAT with a procedural pass preserves detailed authored motion while adding variation at runtime... more alive and less repetitive without rebaking."

Codrops case studies: Vivid, Run Rob Run, and Juan Mora Romero

Sources: tympanus.net/codrops/2026/09/15/vivid-...webflow-experience/, /2026/08/20/run-rob-run-.../, /2026/10/22/juan-mora-romero-portfolio/. - VIVID by Serhii Polyvanyi (Webflow template): THERE IS NO SCROLL - "it looks as though you're scrolling through a website. You're not." Wheel/swipe gestures are intercepted, translated into forward/backward INTENTIONS, and a state machine runs section transitions; navigation locks mid-transition and a small QUEUE holds the next intention so mid-transition swipes wait instead of getting lost. Each section registers forward/backward. "It's more work than a conventional scroll. In return, it gives us control over how one visual state becomes another." Origin: a Dribbble shot people asked for in Webflow - "rather than rebuilding the shot as a static website... something you could actually push against." Division of labor: Webflow handles the static skeleton (typography, layout, styles, states); custom code handles "the weird stuff" (canvas pixel transitions, text shuffle via TreeWalker that preserves the original HTML and never breaks words, SVG stroke-dashoffset nav icons). Cursor trace: a CIRCULAR BUFFER of 30 points carrying position+velocity+timestamp, passed into a shader as arrays; each block reads all 30 to compute its pull (cf. ghost-trails). - RUN ROB RUN by Robert Aperios (music-reactive goo, Three.js WebGPU): the goo as "an object with presence" - "alive enough to carry the emotion of the page, but controlled enough that it still worked as an interface." LAYERED MESHES sharing one deformation core with different materials/responses: refractive outer shell, dense orange core (weight and identity), thin shimmer coat. SCROLL MORPH organic->cube: organicMix = 1-smoothstep(0.55, 0.98, p) while cubeMix = smoothstep(0.68, 0.995, p) - the OVERLAPPING ranges keep the goo character early and still land a clean cube; cube projection pulls each vertex toward the nearest cube face. MUSIC SELECTIVITY is the lesson: "the goo does not react equally to every sound" - early even response made busy songs feel noisy and hi-hats moved the shape too much; weight the response toward kicks/claps/four-to-the-floor and dampen high-frequency transients so they add energy without driving the main shape. Portfolio psychology (cf. Tkachev): "not about calling the site perfect. It is about finally reaching something I can sit with, share, and keep building from."
