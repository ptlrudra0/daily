The Craft Pack

A condensed starter: typography systems, grid and composition, colour, imagery and a final QA pass in one place.

Craft pack

The library's rules, distilled into one checklist.

0. How to use

Per variant: pick one primary style (section 6), at most one secondary. Write a short first (4-6 hex colours with roles, 1-2 typefaces with roles, layout concept, 3 principles that make it unlike other variants). Derive accent and layout from the person's subject, not defaults. Then apply sections 1-5 and filter with section 7.

1. Typography systems

  • Body 15-25px, line-height 120-145%, line length 45-90 characters; all-caps only for under one line, with +5-12% letterspacing; minimal bold/italic; curly quotes; centred text sparingly.
  • Scale: max ~3 sizes per view (one display, one body, one small); hierarchy by size AND weight, not colour alone; display 80-160px for a hero statement.
  • Pair one expressive display face with one neutral functional sans; contrast in structure, harmony in mood. Default Inter/Poppins/Montserrat everywhere is an AI tell. Free Google Fonts options and pairing study: typewolf.com/google-fonts.
  • Fluid type with clamp: utopia.fyi; utopia-core has an ISC declaration but no licence file, so copy the idea, not the package.
  • Style-specific type: brutalist = oversized grotesque as the image or raw monospace defaults (Brutal Web, brutalistwebsites.com); retro 1998 = Times serif + hard blue underlined links (timetowarp.com); clay/soft-3D = monospace on cream (davesocozy.com); editorial = rule-led masthead with huge logotype and mono uppercase labels (The Verge); warm brand = soft display serif with an italic emphasis line (Mailchimp). All.

2. Grid and composition

  • Group by proximity: the gap between groups must clearly exceed the gap inside groups; this replaces boxes and lines.
  • Focal object on a third-line intersection or the 0.618 line; asymmetry (5/7 text/image or 61.8/38.2) for energy, symmetry for calm/trust.
  • 12-column grid, few strong edges, break the grid deliberately (bleed, overlap, rotate).
  • One hero object is the largest thing by a clear margin. Examples: Marble Bust 01 (Poly Haven CC0, 17,456 triangles, 1k set ~0.9 MB); davesocozy's glossy clay flower on a cream grid panel.
  • Above the fold matters: 57% of viewing time above the fold, 74% in the first two screenfuls.
  • Pacing: few sections, deep interaction (Igloo had 3 sections and won SOTY 2024).
  • Navigation: reduce to logo + 1 CTA + menu on mobile (Figma, Linear, Apple seen at 1280 and mobile); mega-menu and progressive disclosure per NN/g; keep nav labels few (Hick, Miller). Touch targets 44px.
  • Responsive: viewport meta; never disable zoom; width/height on images; flex/grid with fr; recompose for 390px, do not shrink.

3. Motion principles

  • Feedback 100-160ms; dropdown/tooltip 125-250ms; modal 200-500ms; most UI 100-400ms; 500ms+ feels like a drag; enter slightly longer than exit (300 in, 200-250 out).
  • Easing: ease-out for enter/exit, ease-in-out for on-screen moves, linear only for marquees. Curves: cubic-bezier(0.23,1,0.32,1) out; (0.77,0,0.175,1) in-out; (0.32,0.72,0,1) drawer. Material standard (0.2,0,0,1); emphasized decelerate (0.05,0.7,0.1,1). Never ease-in on UI.
  • Press scale 0.97; never animate from scale(0), start 0.9+; set transform-origin to the trigger.
  • Scroll: Lenis (MIT) + GSAP ScrollTrigger (GSAP is now free). Recipe: new Lenis({autoRaf:false}); lenis.on('scroll',ScrollTrigger.update); gsap.ticker.add(t=>lenis.raf(t*1000)); gsap.ticker.lagSmoothing(0);. CSS scroll-driven animations (animation-timeline: view) for simple reveals. No scroll-jacking that fights the wheel.
  • Scroll reveals: 100-400ms, once, one element type at a time (Apple did best in NN/g's study).
  • Choreography: stagger siblings 30-80ms, hero leads, one direction of travel, one orchestrated entrance per section, not the same fade-up everywhere.
  • View Transitions API for page and thumbnail-to-detail morphs, with a plain fallback.
  • Reduced motion: no parallax/zoom/autoplay loops, crossfade instead, do not init Lenis; autoplay over 5s needs a pause control (WCAG 2.2.2).
  • Cinematic hero reveals of 600-1200ms are fine once. Reserve WebGL for the single hero; fake expensive materials with textures and math (Lando Norris site did, and ships small bundles via ogl.js, gltf-transform).

4. Palette strategies

  • Derive the accent from the subject (materials, artifacts), not from a default; keep saturation just below neon; build hover/border/focus/text steps from one 12-step scale (Radix gold/bronze for champagne accents).
  • Dark UI: body text ~92% white not pure white, glow behind the accent instead of heavy shadows.
  • Contrast: do not drop text below WCAG AA to de-emphasise.
  • Palettes seen: black + one accent; cream (#EDE5D3-ish) + olive clay + dark brown (davesocozy); off-white + black outlines + flat pink (Gumroad); warm yellow on photo + soft serif (Mailchimp); royal blue + cream grotesque (Heist on Brutal Web); hot magenta + white caps (PSP Production); white + mint highlight + blue CTA (Notion).
  • Colour psychology claims stay hypotheses; consistency beats meaning.
  • Palette tools: Coolors (check export formats/prices); Radix colours (MIT).

5. Techniques and teardown takeaways

  • Igloo (SOTY 2024): previs/grey-box the journey first; one consistent signature effect (chromatic aberration + displacement + frost transitions); unique variation per item; tune for low-end devices.
  • Lando Norris (SOTY 2025): layers/render targets for masking the hero; fake glass with fract+noise+reflection texture; sync WebGL with DOM; test mobile early.
  • Messenger (SOTY 2025): start from a feeling and real-world references; a technical constraint (spherical world) became the style.
  • Lusion 2019/v3: bake animation into textures (11-keyframe vertex animation in PNG, 16-bit packing), two-colour palette. Preloader never finished in my tests.
  • Luxury = care: one image art direction, signature + functional face, performance, rare precise motion. Not black + gold.
  • Photos: real, informative images get looked at; decorative stock gets ignored.
  • Portfolio basics: person first, selected work with outcomes, clear contact.
  • Signature microinteraction repeated consistently = interaction language.

7. Anti-slop filter (apply last)

Wave 1 tells: Inter/Roboto only, purple-indigo gradients and gradient headline text, stock order (centred hero, pill badge, two buttons, logo row, 3 feature cards, pricing, CTA), rounded-2xl card kit with same shadow, reflexive glass/blur/glow, fade-up on every section, bounce easing, count-up stats, invented numbers. Wave 2 tells (from "make it less AI"): warm editorial cream+serif+terracotta, dark near-black + one acid accent, broadsheet cosplay hairlines, template eyebrow caps on every heading. Claim about Anthropic's skill is as reported by that article. Rule: every visible decision must be one you made for THIS person.

Dark-UI grain recipe (texture vein synthesis)

Dark-UI grain: two-tier spec (verified against Linear.app production CSS)

  • TIER 1 (page whisper grain): neutral alpha-noise tile (grey ~186 RGB, alpha variance), 256-512px tile, mix-blend soft-light, 3-4% effective opacity - for full-page backgrounds.
  • TIER 2 (feature panels, Linear-style): same tile at 256px background-size, mix-blend OVERLAY, absolute inset:0 (or 1px inside border), border-radius:inherit, pointer-events:none. Opacity tiers:.9 strong /.6 subtle /.25 over glows; strong tier gets a 6% white (#ffffff0f) wash layer on top.
  • Tile spec: RGBA PNG, R=G=B (hue-neutral), texture encoded in ALPHA channel (range ~75-255) - hue-neutral tiles can't colour-shift any background.
  • Universal rules unchanged: never animate, strip in print/forced-colors, contrast check text over grain, isolate in its own layer (nodlume negative-z rule).
