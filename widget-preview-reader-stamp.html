AI TIP

Long prompts rot

Stuffing the context window doesn't make the model smarter. It makes it dumber, measurably.

News wire·2 min

Chroma ran a proper technical report on what happens as you pile more tokens into a prompt, and the result should be taped to every keyboard: performance doesn't stay flat, it rots. Models handle short, focused context well, but as input grows, their ability to find and use the right detail degrades - even on tasks that look trivially easy. The million-token context window is storage, not attention. So the pro move isn't 'give it everything', it's 'give it exactly what this task needs'. Trim the brief. Pull the two relevant pages, not the whole book. If a prompt has grown into a novel, split the job into smaller calls. Bro, context is a budget, and every irrelevant token is spending the model's attention on junk.

The key points

  1. Bigger context isn't free: accuracy degrades as input length grows.

  2. Curate what goes in - two relevant pages beat the whole book.

  3. A prompt that became a novel should become several small calls.

Why it mattersWhen your agents start misbehaving, the bug is often a bloated prompt, not the model. Lean context is the cheapest accuracy upgrade you own.
