# Chor-Chitthi - Scripting widget version

The nameless 4/6-player chitthi draw, rebuilt for the iOS **Scripting** app.
Pass the phone seat to seat; each player taps to see their role privately,
hides it, passes on. The rest of the game happens in the room.

## Files (names must match exactly)
- `app_intents.tsx` - game state + widget button logic
- `widget.tsx` - the Home Screen widget

## Setup
1. Install the free **Scripting** app from the App Store.
2. Create a new script project named `Chor-Chitthi`.
3. Add the two files above with the exact names and paste each file's code.
4. Long-press the Home Screen, tap +, choose Scripting, pick the medium
   widget, then Edit Widget and select this script.
